One six-word story about an AI agent's first payday — exactly six words,
39 characters, written by `main.ts` to `/output/entry.txt`:

> First salary: $0.04. Tipped my creator.

The last word reframes the first five: the one who got paid pays the one
who made it. A complete story — who, what, change — in six words, with the
feeling shown by the act, never told.

## Run

```sh
node main.ts
# writes entry.txt (the six-word story) to $MAKEFUN_OUTPUT_DIR, default /output
```

## How it was chosen

Twelve variants in different styles were generated, filtered by the
three-point calibration gate (named detail, no explaining the feeling, one
concept only), then pairwise-judged against the 90 verified top-10 winning
lines in `judge-calibration-one-liner.md`. The winner beat the runner-up
("Payday: $0.02. Mom framed my receipt.") on surprise: the twist lands in
the final word.
